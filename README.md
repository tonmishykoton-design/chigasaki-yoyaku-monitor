# 茅ヶ崎市施設予約 空き状況モニター(新システム対応版)

2026年9月に茅ヶ崎市公共施設予約システムがリニューアルされたため(新URL:
https://k7.p-kashikan.jp/chigasaki-city/ )、それに合わせて全面的に作り直したバージョンです。

新システムはフレームを使わない普通のページ構成で、「期間の空き状況」機能を
使うと1つの施設につき約40日分の空き状況が1画面でまとめて見られるため、
旧システム版よりコードがシンプルになっています。

## 監視対象(初期設定)

- 総合体育館:柔道場、剣道場、オーケストラ練習室
- 市体育館:柔剣道場
- 曜日:毎週日曜日
- 時間帯:18:00〜21:00(18・19・20の3列すべてが○の時のみ通知)
- 期間:サイトの「期間の空き状況」で表示される約40日分

変更したい場合は `config.py` を編集してください。

## セットアップ手順

以前のセットアップ(Gmailアプリパスワード発行、GitHub Secrets登録)が
既に完了していれば、そのまま使い回せます。GitHub Secretsの
`GMAIL_USER` / `GMAIL_APP_PASSWORD` / `NOTIFY_TO` は変更不要です。

### ファイルの置き換え

このフォルダの中身を、リポジトリの同じ場所にあるファイルへ
上書きコピーしてください(中身をまるごと置き換える形です)。

```
リポジトリ直下/
├── check_availability.py   ← 新しい内容に置き換え
├── config.py                ← 新しい内容に置き換え
├── requirements.txt         ← 変更なし(念のため置き換えてもOK)
└── .github/workflows/check.yml  ← 変更なし(念のため置き換えてもOK)
```

### 動作確認

1. GitHubの `Actions` タブ → 「茅ヶ崎市施設予約 空き状況チェック」を開く
2. 右上の `Run workflow` から手動実行
3. 実行ログの中に `[デバッグ] 総合体育館/柔道場 判定結果(空き日): [...]` の
   ような行が出て、実際のサイトの表示と一致しているか確認する

## 注意点

- 新システムはフレームを使わないため、以前悩まされた「フレームが消滅する」
  問題は原理的に発生しません。ただし全く別のシステムなので、初回実行時に
  細かい調整が必要になる可能性はあります。
- 施設名や建物名のボタンをテキストで探してクリックする方式のため、
  サイト側でボタンの表記が変わった場合は `config.py` の名称も
  合わせて変更してください。
